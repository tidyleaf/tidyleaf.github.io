# ChatGPT 資料夾怎麼整理：專案、封存、搜尋與資料夾擴充功能

ChatGPT 沒有單純的「資料夾」。最接近的內建功能是**專案（Projects）**：在側邊欄建立專案，再把對話拖進去，或從對話的「...」選單選「移至專案」。專案可以當成幾個大主題的資料夾，但它沒有子資料夾，會改變裡面對話的行為（套用專案的指示和檔案），而且刪除專案會連同裡面的對話一起刪掉。想整理得更細，可以搭配**封存**和**搜尋**，或在側邊欄加一個資料夾擴充功能。以下逐一說明每種做法能做什麼、不能做什麼。

## 做法一：用 ChatGPT 專案當資料夾（內建）

專案是一組共用檔案和自訂指示的對話。它顯示在側邊欄的聊天紀錄上方，所以也能當資料夾用。依 OpenAI 的說明，專案適合會持續一段時間、需要反覆用到同一批檔案的工作。

怎麼用：

1. 在側邊欄選「新專案」，取個名字。可以點專案名稱前的圖示換顏色和符號，方便辨認。
2. 把現有對話從聊天紀錄拖到專案上，或開啟對話的「...」選單，選「移至專案」。手機 App 上是長按對話再選目的地。
3. 想把對話移出來，在專案裡對那則對話用同一個選單。
4. 在專案裡開的新對話會自動歸到這個專案。

用之前要知道的事：

- **專案不只是資料夾。** 移進專案的對話會套用專案的指示和檔案。這正是專案的用途，但也代表你沒辦法只把它當標籤，背景脈絡一定會跟著進來。
- **專案是平的。** 沒有子資料夾，也不能在專案裡再放專案。
- **一則對話只能放一個地方。** 對話要嘛在某個專案裡，要嘛在一般聊天紀錄裡，不能同時歸到兩個主題。
- **刪除專案會刪掉裡面的對話**，連同檔案和指示。想保留的對話請先移出來。
- **舊的聊天紀錄不會自動分類。** 每一則都要自己動手移。
- **方案限制會變。** 專案原本只開放給付費方案，後來也開放給免費帳號；檔案數量等上限也調整過。請以你帳號裡看到的畫面和 OpenAI 說明中心為準。

專案適合需要共用背景的主題，例如一個客戶、一門課、一份長篇寫作。只是想「把食譜相關的對話放在一起」的話，專案就有點重了。

## 做法二：把用完的對話封存

封存會把對話從側邊欄拿掉，但不會刪除。開啟對話的「...」選單，選「封存」即可。

**ChatGPT 封存的對話在哪裡？** 在「設定」→「資料控管」→「已封存的聊天」。在那裡可以打開或解除封存，封存的對話也仍然會出現在 ChatGPT 的搜尋結果裡。

封存本身不會幫你分類，但能讓要捲動的清單變短。一個簡單的習慣：進行中的工作留在側邊欄或專案裡，其餘的每週封存一次。

## 做法三：搜尋，加上好認的標題

ChatGPT 的搜尋（側邊欄的放大鏡，或 Windows 按 Ctrl+K、Mac 按 Cmd+K）會找遍你的對話，包含已封存的。兩個習慣能讓搜尋好用很多：

- **替對話改名**（「...」選單 →「重新命名」）。自動產生的標題像「Python 錯誤修正」，很難跟另外二十則分開；改成「發票腳本：CSV 日期錯誤」就一眼認得出來。
- **搜尋只會出現在那則對話裡的詞**，例如專案名稱、函式名稱、地名或人名。

搜尋解決的是「那則對話在哪？」，不是「把跟 X 有關的都列出來」，所以它是資料夾的補充，不是替代品。

## 做法四：資料夾擴充功能

有幾個瀏覽器擴充功能會在 ChatGPT 側邊欄加上真正的資料夾。這類資料夾是擴充功能自己記的標籤：對話仍留在 ChatGPT 原本的位置，背景脈絡不會改變，從資料夾移除或刪除資料夾也不會刪掉對話。安裝任何一個之前，先確認三件事：

1. **資料夾存在哪裡。** 只存在你的裝置上，還是存在開發者的伺服器？
2. **會送出什麼、送給誰。** 整理對話的擴充功能讀得到你的對話清單，隱私權政策應該寫清楚哪些資料會離開你的瀏覽器。

## 該用哪一種？

| 你想要 | 用這個 |
|---|---|
| 幾個大主題，共用檔案和指示 | ChatGPT 專案 |
| 側邊欄短一點，但什麼都不刪 | 封存 |
| 找一則記得某個關鍵字的對話 | ChatGPT 搜尋，加上清楚的標題 |
| 很多個小資料夾，或歸檔時不想改變對話的背景 | 資料夾擴充功能 |
| ChatGPT 和 Claude 的對話放在同一組資料夾 | 同時支援兩者的擴充功能，例如 Tidyleaf Folders |
| 手機上也要有資料夾 | 專案（擴充功能只在電腦版瀏覽器運作） |

多數人最後是混著用：兩三個重要主題用專案，其他零散的用資料夾擴充功能或封存處理。

## 常見問題

**ChatGPT 可以建立資料夾嗎？**
沒有資料夾這個功能。內建分組的方式是專案，可以當成第一層資料夾。想要一般的資料夾、子資料夾，或分很多組，就要用瀏覽器擴充功能。

**ChatGPT 封存的對話在哪裡？怎麼解除封存？**
在「設定」→「資料控管」→「已封存的聊天」。打開清單後，可以直接開啟對話，或選擇解除封存，讓它回到側邊欄。

**ChatGPT 專案不見了怎麼辦？**
先確認登入的是同一個帳號（如果你有團隊或企業版工作區，也確認切換到的是同一個），再展開側邊欄的專案區塊看看。如果你之前看到的「資料夾」其實是擴充功能加的，它可能被停用、移除，或因 ChatGPT 改版而失效；也可能你換了瀏覽器或設定檔，因為很多擴充功能只把資料夾存在那一個瀏覽器裡。

**刪除 ChatGPT 專案會刪掉裡面的對話嗎？**
會。刪除專案會一併刪除裡面的對話、檔案和指示。想保留的對話請先移回聊天紀錄。用我們的擴充功能時，刪除資料夾只會清空資料夾，對話仍留在 ChatGPT。

**可以在專案裡再分資料夾嗎？**
不行，專案沒有子資料夾。想再細分，可以用資料夾擴充功能另外替對話分組；擴充功能的資料夾是自己記的標籤，不會改動 ChatGPT 的專案結構。

想把對話另外存一份在 ChatGPT 之外，請見 [ChatGPT 對話怎麼匯出](chatgpt-export-conversation-zh-tw)。英文版說明：[How to organize ChatGPT chats into folders](organize-chatgpt-chats-folders)。
