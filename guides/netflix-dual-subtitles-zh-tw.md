# Netflix 雙字幕怎麼開：同時顯示中文與英文字幕

Netflix 沒有內建雙字幕。不論是電視、手機、平板 App 還是網頁版，一次都只能顯示一種字幕語言，選第二種就會把第一種換掉。想要上面英文（或影片原文）、下面中文兩行同時出現，唯一的做法是**在電腦上用 Chrome 或 Edge 開 netflix.com，再裝一個雙字幕擴充功能**，免費的就有好幾個。

## Netflix 本身能做到什麼

- **單一語言字幕：** 播放時點右下角的對話框圖示（音訊與字幕），選一種字幕。
- **可選的語言取決於影片和地區。** 選單通常只列幾種，影片實際上可能還有更多語言，只是沒顯示給你。
- **沒有雙字幕模式**，電視 App、手機與平板 App、網頁版都一樣。

不裝任何東西的土法是：先用一種語言看一段，倒轉十秒再切換另一種。偶爾查一句可以，看完一整集會很累。

## 開啟 Netflix 雙字幕的步驟

1. **用電腦。** 用 Chrome 或 Edge 開 netflix.com（Mac 也可以用 Chrome）。如果你挑的擴充功能有 Firefox 版，也可以用 Firefox。
2. **到 Chrome 線上應用程式商店安裝雙字幕擴充功能。** 選擇在下一節。
3. **播放一部有字幕的影片**，從工具列上的擴充功能圖示或播放器上的按鈕打開設定。
4. **選兩種語言**，例如上面英文、下面繁體中文。
5. **調整字體大小和位置**，不要讓兩行字幕擋住畫面。

## 雙字幕擴充功能怎麼選

### Language Reactor

Language Reactor（舊名 Language Learning with Netflix）是最多人知道的選擇，可以用在 Netflix 和 YouTube。它是完整的學習環境：兩行字幕、滑鼠移過去就跳出的字典、每句自動暫停、影片旁邊的字幕列表。免費版使用 Netflix 本身提供的字幕；付費的 Pro 版加上機器翻譯（用在 Netflix 沒有第二語言字幕時）、配音影片的語音辨識、收藏單字並匯出到 Anki，據其常見問題說明，機器翻譯有每日用量上限。價格和限制會變動，請以 [languagereactor.com](https://languagereactor.com/pro-mode) 為準。

適合想要一整套學習工具的人。如果你只是要多一行字幕，它的功能可能多於你需要的。

### 只做雙字幕的小型擴充功能

在 Chrome 線上應用程式商店搜尋「Netflix 雙語字幕」會找到好幾個。很多中文教學推薦的 NflxMultiSubs 也是其中之一，但那些步驟多半寫於 2021 年，裝之前先看商店頁面最近的評論，確認現在還能用。安裝前也檢查這四點：

1. **用的是 Netflix 自己的字幕，還是機器翻譯？** 人工字幕比機器翻譯好。比較好的做法是兩行都用 Netflix 的字幕，缺語言時才翻譯。
2. **中文、日文、韓文是文字還是圖片？** Netflix 常把中日韓字幕以圖片形式送出。拿不到文字版的擴充功能，就沒辦法改字體、翻譯或加注音。
3. **快轉、跳過片頭、自動播下一集時會不會跟上？** 商店評論通常會提到。
4. **會把什麼資料送到哪裡？** 隱私權政策應該寫出它連線的每個伺服器。只需要 netflix.com 卻要求讀取所有網站的，要小心。

## 手機、電視、iPad 能開雙字幕嗎

| 在哪裡看 | 能不能雙字幕 |
|---|---|
| 電腦上的 Chrome 或 Edge（Windows、Mac 都可） | 可以，要裝擴充功能 |
| 電腦上的 Firefox | 要有 Firefox 版的擴充功能 |
| Mac 上的 Safari | 要有 Safari 版的擴充功能，選擇很少 |
| 電視、iPhone、iPad、Android 的 Netflix App | 不行，App 裡無法執行擴充功能 |
| 電視，透過筆電 | 可以：筆電開擴充功能，再用 HDMI 線或投影接到電視 |

用 Chromecast 從手機投影，播的是 Netflix App 的畫面，一樣只有一種字幕。

## 用雙字幕學語言的小技巧

- **把正在學的語言放在上面**，母語放下面，眼睛會先看到目標語言。
- **聽得懂大部分時，隱藏你已經懂的那一行**，跟不上再打開。
- **學的語言盡量用人工字幕。** 機器翻譯可以幫你理解意思，但句子常不自然。選原文就是你在學的語言的影片。
- **注音或拼音是程式產生的，不是從聲音聽出來的。** 「行」「了」這類破音字偶爾會標錯，當作參考就好。台灣學校教注音，其他地方多用拼音，選你課本用的那一種。
- **看看過的片子。** 已經知道劇情，注意力就能放在語言上。

## 所有方法都有的限制

- **第二種語言要存在，或者靠翻譯。** 影片沒有那種語言的字幕時，只能用機器翻譯，俚語、人名、笑話容易翻錯。
- **Netflix 會更新播放器。** 擴充功能讀的是播放器載入的資料，更新後可能暫時失效，等開發者修正。兩行突然不見時，先到商店頁面看有沒有更新。
- **一次只開一個雙字幕擴充功能。** 兩個同時開會互相疊在一起。廣告阻擋或其他 Netflix 相關擴充功能也可能衝突，有問題時先暫停它們試試。

## 常見問題

**Netflix 不裝擴充功能可以開雙字幕嗎？**
不行。Netflix 在所有裝置上都只能一次顯示一種字幕語言，兩行字幕需要電腦瀏覽器加擴充功能。

**Netflix 雙字幕手機、平板、iPad 可以用嗎？**
不行。手機和平板上的 Netflix App 不能裝擴充功能。要用電腦的 Chrome 或 Edge 開 netflix.com。

**Netflix 雙字幕電視可以用嗎？**
電視 App 不行。可行的做法是用筆電播放並開擴充功能，再用 HDMI 線或投影接到電視。

**Mac 可以開 Netflix 雙字幕嗎？**
可以，在 Mac 上用 Chrome 或 Edge 安裝擴充功能即可。Safari 需要專為 Safari 做的擴充功能，選擇很少。

**為什麼第二行字幕沒出現？**
通常是影片沒有那種語言的字幕、而擴充功能不會翻譯，或是 Netflix 更新了播放器、擴充功能還沒跟上。先換一部影片試試，再檢查擴充功能有沒有更新。
